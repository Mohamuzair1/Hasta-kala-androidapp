About this site

This page is hosted on Netlify. Netlify serves static websites only. The Hasta-Kala Shop Android app runs on phones and tablets — it is not executed on Netlify.

Install the app

  1. Build an APK in Android Studio: Build → Build Bundle(s) / APK(s) → Build APK(s)
  2. Upload the APK to GitHub Releases (or share the file).
  3. Replace the link below with your release asset URL, then redeploy this site.
